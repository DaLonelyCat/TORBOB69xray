## 4. Priority Issues (P1-P3)

- **[P1] Low Contrast on Verdict Jump Button & Badges** (`styles.css:210, 296, 544`): Fails WCAG AA (worst: 2.7:1 on gold button, 3.4:1 on red tags). *Fix*: Darken button text to bronze `#161208` on gold; brighten tag text to `#ff7080`. -> `/impeccable colorize`
- **[P1] Missing `prefers-reduced-motion` Safety** (`styles.css:44`, `app.js:192`): Violent screen tremors (`courtroomTremor`) execute on body without accessibility guards. *Fix*: Wrap shakes in `@media (prefers-reduced-motion: no-preference)` and provide calm visual feedback for reduced motion. -> `/impeccable polish`
- **[P1] Irreversible Verdict State & Missing "Appeal / Reset"** (`app.js:220`): Delivering the verdict permanently locks the holding cell, requiring a full page refresh to re-experience the audio-visual climax. *Fix*: Add an "APPEAL / RETRIAL" state or re-strike action. -> `/impeccable delight`
- **[P1] Synchronous Browser `alert()` Shatters Immersion** (`app.js:275`): Copying the verdict URL triggers a native browser popup. *Fix*: Replace with an in-page golden wax seal toast notification. -> `/impeccable polish`
- **[P1] Mechanical Detector Slop Cleanup** (`styles.css`): 22 detector findings. *Fix*: Remove pulsing dot, replace diffuse halos with crisp double borders, replace side tabs with indented blockquotes, use exponential easing. -> `/impeccable distill`
- **[P2] Undersized Touch Targets (<44px)** (`styles.css:100, 486, 550`): Buttons measure 29px–39px. *Fix*: Enforce `min-height: 44px; min-width: 44px`. -> `/impeccable adapt`
- **[P2] Missing Active Visual State on Evidence Cards** (`app.js:65`): Ledger cards don't highlight when their corresponding video segment is active. *Fix*: Add `.active-evidence-card` with glowing border. -> `/impeccable layout`
- **[P2] Lack of Keyboard Accelerators** (`app.js`): Interactive soundboard experience lacks hotkeys. *Fix*: Add keyboard listeners (`O`, `G`/`Space`, `M`, `1-6`, `Esc`). -> `/impeccable harden`
- **[P2] Forced Layout Reflow in Screen Shake** (`app.js:195`): Synchronous DOM reflow via `void document.body.offsetWidth`. *Fix*: Isolate animation to `<main>` without layout thrashing. -> `/impeccable optimize`
